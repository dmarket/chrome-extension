# Changelog

All notable changes to the DMarket Trust Shield Chrome extension are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and commit messages
follow [Conventional Commits](https://www.conventionalcommits.org/). Versions are the Chrome manifest
version in `apps/dmarket-chrome-extension/src/manifest.json`.

Each release needs a `## [<version>]` section here before its release branch is pushed: CI refuses to
tag a version without one, and the section becomes the GitHub Release notes. See "Releases" in the
README.
